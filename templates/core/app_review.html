Why Native iOS App?

While the core app is web-based, the native iOS wrapper provides essential functionality:

  • HealthKit Integration - Sync health data from Apple Health (steps, heart rate, sleep, etc.)
  • Native Settings - iOS-native settings screen for HealthKit permissions
  • Secure Token Storage - Keychain-based authentication
  • Push Notifications - Native notification support (future)

HealthKit Integration

The app integrates with Apple HealthKit to sync health data. This is a key reason for the native iOS app.

How to Test HealthKit

  1. Open the iOS app and log in with the demo account
  2. Tap the gear icon (Settings) in the top-right of the web view
  3. In the native Settings screen, tap "Authorize HealthKit"
  4. Grant permissions for the health data types you want to sync
  5. Tap "Sync Now" to pull data from Apple Health
  6. Return to the Health section to see synced data

HealthKit Data Usage

Health data synced from HealthKit is only used to display personal health trends within the app. It is:

  • Never sold or shared with third parties
  • Never used for advertising
  • Stored securely and encrypted
  • Deletable at any time by the user

Account Management

Delete Account

Users can permanently delete their account and all associated data:

  1. Navigate to More > Profile
  2. Click "Delete Account" (bottom right of profile card)
  3. Optionally export data before deletion
  4. Confirm deletion by typing "DELETE"
  5. Account and all data are permanently removed

Export Data

Users can download all their personal data (GDPR compliance):

  1. Navigate to More > Preferences
  2. Scroll to bottom and click "Export Your Data"
  3. Choose JSON or CSV format
  4. Download contains all user content (journals, health, goals, etc.)

Data Retention

  • Active data: Kept while account is active
  • Deleted items: 30-day recovery period, then permanent deletion
  • Account deletion: All data permanently removed within 30 days
