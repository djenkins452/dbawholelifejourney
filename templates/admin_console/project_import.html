JSON File Format

The JSON file must follow the WLJ Executable Task Standard:

{
  "project": {
    "name": "Project Name",
    "description": "Optional description"
  },
  "tasks": [
    {
      "phase": "Phase 1",
      "name": "Task Title",
      "description": {
        "objective": "What the task accomplishes",
        "inputs": ["Required context or resources"],
        "actions": ["Step 1", "Step 2"],
        "output": "Expected deliverable"
      },
      "priority": "High|Medium|Low",
      "status": "New|Ready|In Progress",
      "effort": "Low|Medium|High"
    }
  ]
}

Note: All tasks must have the full description object with objective, inputs, actions, and output. Tasks will be created in Backlog status by default.
