Security Requirement

Privileged accounts have access to sensitive data and administrative functions. Multi-factor authentication protects your account from credential theft and unauthorized access.

Why is MFA required?

  • Staff/admin accounts can access user data and system settings
  • Passwords alone are vulnerable to phishing and credential theft
  • Biometric authentication is resistant to remote attacks
  • This is a security best practice for privileged access

How to set up MFA:

  1. Click the "Set Up Biometric Login" button below
  2. Follow your browser's prompts to register Face ID, Touch ID, or a security key
  3. Once registered, you'll be able to access the application
