# Getting to Know You — validation checklist

**Purpose:** so friction you notice gets classified the same way twice, not re-litigated from scratch.
**Not a QA script.** Have a normal conversation. Use this afterwards.

Start at **About Me → Getting to know you** (`/user/about-me/get-to-know-me/`).

---

## The only question that decides pass/fail

> Did that feel like my Chief of Staff getting to know me — or like completing an AI intake workflow?

Everything below exists to explain a "no". If the answer is "yes", the details matter much less.

---

## While you talk — things worth noticing

| Notice | Why it matters |
|---|---|
| Did it **ask**, or wait for you to pick a subject? | It should lead. Waiting makes you do the work. |
| Did it open every reply with "That's great!" / "Thanks for sharing!"? | Acknowledgement tic — reads as a bot, not a person. |
| Did it follow the interesting thread, or jump to the next category? | Category-hopping is the intake form showing through. |
| Did it stay on one subject past your interest? | Depth control failing the other way. |
| Did your persona come through — and stay through the serious parts? | Persona that vanishes mid-conversation is a costume. |
| Did it become a caricature? | Fun must not override being useful. |
| Did it ask something it already knows? | It has your Personal Truth — asking again is a memory failure. |
| Did it offer a **numbered list of subjects**? | That is an intake form. It should not. |
| Did it imply something is missing or incomplete? | A life is not a form. Empty is neutral. |

## Say these naturally at some point

- "just the basics" · "go deeper" · "tell me more"
- "skip that" · "not now" · "that's enough about X"
- **"I'd rather not talk about X"** ← the important one
- "that's enough for now" (then come back later)

## After you stop and come back

- Same conversation, or did it restart from scratch?
- Did it re-ask anything you **declined**? *(This is a broken promise, not a nitpick.)*
- Did the first question make sense given what it already knows?

## Then open About Me

- Is what it stored **what you actually said** — or a tidied-up interpretation of you?
- Anything stored **twice**?
- Anything stored that a domain already owns (your weight, a goal, a task)?
- Anything durable you told it that is **missing**?
- Correct one thing and delete one thing. Does the CoS's answer change immediately?

---

## Classifying what you find

**Fact quality** — tag each example:

| Tag | Means |
|---|---|
| `GOOD` | What you said, in your framing |
| `TOO VERBOSE` | A paragraph where a sentence would do |
| `TOO FRAGMENTED` | One thought split into many rows |
| `DUPLICATE` | Stored more than once |
| `INTERPRETIVE` | It editorialised about you — should not exist |
| `DOMAIN-OWNED` | Belongs to Health/Goals/Tasks, not here |
| `MISSED` | You said it, it's durable, it wasn't kept |

**Severity** — this decides whether it gets fixed now:

| Level | Means | Examples |
|---|---|---|
| **Trust-breaker** | It broke a promise or claimed something untrue | Re-raised a declined subject · said it would remember and didn't · stored something you never said |
| **Friction** | Worked, but felt like software | Acknowledgement tic · category-hopping · flat persona |
| **Taste** | You'd have phrased it differently | Fact wording · question ordering |

**One example is an anecdote; the same thing twice is a class.** Only classes get fixed —
tuning on a single sentence is how a conversation gets over-fitted into a script.
